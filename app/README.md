# Laço (aplicativo)

Aplicativo mobile privado para casais, feito com Expo, React Native e TypeScript.

A documentação de produto, decisões, arquitetura e UX fica em [`../docs`](../docs). As regras de trabalho do projeto estão em [`../CLAUDE.md`](../CLAUDE.md) e as de Expo em [`AGENTS.md`](AGENTS.md).

## Rodar

```bash
npm install
npx expo start
```

## Verificar

```bash
npx tsc --noEmit
npx expo-doctor
```
