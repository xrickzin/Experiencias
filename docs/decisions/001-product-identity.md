# 001 — Identidade do produto: Laço

**Status:** Aceita

## Contexto
O projeto começou com o nome descritivo "Experiências Compartilhadas".

## Decisão
O produto se chama **Laço**. É um aplicativo mobile privado para **casais**. "Experiências Compartilhadas" deixa de ser nome e fica, no máximo, como descrição conceitual histórica.

A identidade é documentada apenas como **direção conceitual** (intimidade, elegância, acolhimento, leveza, personalidade brasileira, sensação editorial/de álbum). Não é design system.

## Consequências
- O nome técnico (`slug`, `scheme`, identificador do aplicativo) ainda é `app` e está em aberto: [open-questions.md](../product/open-questions.md) T5.
- UX/UI começa em etapa própria: [../ux/README.md](../ux/README.md).
