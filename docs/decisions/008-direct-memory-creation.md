# 008 — Criação direta de Memória

**Status:** Aceita

## Contexto
Muitas experiências aconteceram antes do aplicativo e o casal quer guardá-las. Nossa História só funciona se cada memória tiver quando aconteceu.

## Decisão
- O casal pode criar **um Desejo** ou **uma Memória**. Não se cria diretamente em Planejamento nem em Vivendo.
- Uma Memória criada diretamente exige **título** e **referência temporal** (mês/ano, data, data + horário ou período).
- Uma experiência não vira Memória sem referência temporal; ao finalizar sem data, o primeiro do casal que a definir a fixa.

## Consequências
- Nossa História pode ser preenchida desde o início.
- A precisão temporal faz parte do modelo de dados.

> O planejamento pode ser incerto. A história precisa saber quando aconteceu.
